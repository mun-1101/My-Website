Blocks in Scratch

Block Categories

Motion: Moves and rotates your sprites on the screen.

Looks: Changes how sprites and backgrounds appear or speak.

Sound: Plays music, notes, and audio clips.

Events: Triggers scripts to start when something happens, like a key press.

Control: Manages loops and if-then conditions to guide program flow.

Sensing: Detects touches, mouse positions, and keyboard input.

Operators: Performs math, comparisons, and text joining.

Variables: Stores numbers and words that can change as the game runs.

My Blocks: Lets you create your own custom, reusable blocks.

Extensions: Adds extra tools for things like music instruments or hardware.

Block Shapes

Hat blocks: Have a curved top and sit at the very start of a script to trigger it.

Stack blocks: Have a notch on top and a bump on the bottom to stack in a sequence.

Reporter blocks: Are rounded rectangles that hold values like coordinates or names.

Boolean blocks: Are hexagonal conditions that output true or false.

C blocks: Look like the letter C and wrap around other blocks to loop or test conditions.

Cap blocks: Have a flat bottom and stop a script from running further.
