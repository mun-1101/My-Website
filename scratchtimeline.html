Scratch milestones

-2003: Development begins under Mitchel Resnick and Yasmin Kafai to create a visual coding language for children.

-2004–2006: Early prototypes (Scratch 0.1 through 0.5) are designed, testing block layouts, sprite creation, and paint editor tools.

-March 5, 2007: The very first public Scratch project is created.

-May 10, 2007: Scratch 1.0 is officially released as a free downloadable desktop program.

-2007–2008: Scratch 1.1, 1.2, and 1.3 are released with various bug fixes and block updates.

-April 2009: The 1,000,000th project is shared on the platform.

-2013: Scratch 2.0 launches, moving toward an online platform with custom blocks and browser-based sharing.

-July 2014: ScratchJr is released for younger children.

-January 2, 2019: Scratch 3.0 is officially released, adding tablet support, a redesigned block palette, and HTML5/JavaScript underpinnings.

-2025–2026: Early development work for future iterations of Scratch continues.
